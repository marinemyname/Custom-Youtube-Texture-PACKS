# YouTuber Texture Packs

A collection of texture packs made for or inspired by different YouTubers.

Each creator has their own folder inside `texture-packs/`.

- [Apup](texture-packs/Apup/) NOT RELEASED

## How to download

1. Open the folder for the YouTuber you want.
2. Download the latest `.zip` texture pack file.
3. Follow the instructions in that folder’s `README.md`.

## Adding a new texture pack

1. Create a new folder inside `texture-packs/` using the YouTuber’s name.
2. Add the texture pack `.zip` file.
3. Add a `README.md` explaining the pack, supported game version, and installation steps.
4. Submit a pull request.
